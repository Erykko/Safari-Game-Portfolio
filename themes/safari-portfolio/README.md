# Safari Portfolio

WordPress theme for the Safari Portfolio game-style site. Includes **Safari Portfolio Core** (bundled): custom post types, ACF field groups when ACF Pro is active, seed data, and WP-CLI commands. The plugin is loaded automatically from `plugins/safari-portfolio-core/` when the theme is active.

## WordPress.org submission

Before submitting to the [WordPress Theme Directory](https://wordpress.org/themes/upload/):

1. **Screenshot:** Add `screenshot.png` (1200×900 px) to the theme root. It is required and appears in the directory and in Appearance → Themes.
2. **Contributors:** In `readme.txt`, set `Contributors:` to your WordPress.org username(s).
3. **Zip:** Package only the theme folder contents (no `.git`, `node_modules`, or IDE files).

The theme includes the required files: `style.css`, `index.php`, `comments.php`, `readme.txt`, and uses a standard template structure.
